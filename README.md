# sistema-citas-clinica
Sistema de Citas Médicas para una Clínica

Integrantes

- Jesus Aranda
- Fatima Quiñones

Descripción

Sistema para gestionar citas médicas, pacientes, médicos y consultorios, con validaciones de disponibilidad y estado del médico.

Funcionalidades

- Registrar citas médicas.
- Validar la disponibilidad del médico.
- Validar la disponibilidad del consultorio.
- Comprobar que el médico esté activo y tenga especialidad.
- Modificar y cancelar citas.
